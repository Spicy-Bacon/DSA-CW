Student Society Event Planner Project

1. Overview
This group project aims to create a Student Society Event Planner, allowing a committee for a university student society to evaluate the best possible combination of events to run during the weekend under constraints. As a whole, the code supplied, should print out the best combination of events, under constraints, resulting in the best enjoyment value for the most satisfactory service. 

2. How to run the program
Before runnign the program on any imput files you must make sure those imput files are in the same file as event_planner.py

In a dedicated/ new terminal:
    type "python event_planner.py"
    type the input file you wish the program to use "input_small.txt" for example

This format MUST be followed otherwise the program may terminate. The input_small.txt can be replaced by any of the other selected files as long as it is a .txt file with correct structure and in the same file as event_planner.py.

3. Dependancies / Libraries required
- Up-to-date version of python such as 3.13.5
- Importing the python time library which is used to calculate the time to execute the program
